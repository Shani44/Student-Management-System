The project is organized into the following core directories and modules:   classes/: Contains the core object-oriented class definitions.   Course.php: Handles course-related attributes and operations.   Enrollment.php: Manages student-course enrollments.   Student.php: Defines student-specific properties and behaviors.   Teacher.php: Defines teacher-specific properties and behaviors.   User.php: Base or management class for system users.   config/: Configuration files.   database.php: Handles database connection settings.   public/: Entry points and user-facing web pages.   dashboard.php: Central user dashboard.   enroll_course.php: Page for course registration/enrollment.   index.php: Landing page of the application.   login.php & logout.php: Authentication endpoints.   manage_courses.php: Interface for administering courses.   manage_users.php: Interface for managing user accounts and roles.   sql/: Database scripts.   database.sql: Initial SQL dump/schema for database setup.   templates/: Reusable interface components and role-specific dashboard views.   header.php & footer.php: Common layout partials.   admin_dashboard.php: Administrator view.   student_dashboard.php: Student view.   teacher_dashboard.php: Teacher view.   🚀 FeaturesRole-Based Access Control: Distinct dashboards and permissions tailored for Administrators, Teachers, and Students.   User & Course Management: Admins can manage user accounts and course offerings via dedicated management interfaces.   Enrollment System: Students can browse and enroll in available courses.   Modular Layouts: Consistent look and feel across pages using shared template components.   🛠️ Setup & InstallationClone or Copy the repository into your local web server directory (e.g., htdocs for XAMPP).Database Setup:Create a MySQL database.Import the SQL schema provided in sql/database.sql.   Configuration:Update your database credentials inside config/database.php.   Run the Application:Start your local server (Apache/MySQL) and navigate to public/index.php via your web browser.
